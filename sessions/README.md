# sessions/

Vùng làm việc giữa người dùng, phiên claude.ai và Claude Code. **Không phải tài liệu chính thức**: Fumadocs không đọc thư mục này, trang trong `content/docs` không link tới đây. Xóa cả thư mục khi xong dự án.

| Thư mục | Nội dung |
|---|---|
| `progress/` | Nhật ký phiên, mỗi tháng một file (`2026-11.md`). Cuối phiên thêm một mục: đã làm, vướng, tiếp theo |
| `plans/` | Kế hoạch từng bước và prompt giao Claude Code (`auth.md`, `ui-mock.md`...), lộ trình 34 tuần |
| `reviews/` | Ghi chú review PR khi cần giữ lại |
| `archive/` | Bản cũ chỉ để tham khảo: phân tích gốc, quyết định về cách làm việc |

Quy tắc viết:

- Tài liệu chính thức (`content/docs`) viết như mô tả sản phẩm đang có: không ghi "bước 21", "PR #16", "bạn bảo", không ghi lịch sử thay đổi (git đã giữ).
- Những gì chỉ đúng cho một phiên, một bước, một PR thì viết ở đây.
